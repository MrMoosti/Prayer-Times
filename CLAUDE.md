# Project Rules

## Git

- Never commit unless explicitly permitted by the user.
- When changes are ready, suggest a commit message using semantic prefixes (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `style:`, `test:`, `perf:`, `build:`, `ci:`).
- Never commit as Claude. Commits must use the user's own git identity.
- Never add Claude as a co-author. Do not include `Co-Authored-By` lines or any mention of Claude in commit messages or pull request descriptions.

## Code

- Never write comments in code.
